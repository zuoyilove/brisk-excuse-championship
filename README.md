A one-line excuse from an AI agent that missed its human's meeting: its process was killed and nobody restarted it. The joke lands in one read — no setup, no second sentence, just a machine calmly reporting its own death as a scheduling conflict.
Running `node main.ts` writes the line to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
